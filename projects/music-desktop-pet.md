> 将歌单氛围转化为个性化音灵，并让它真正驻留桌面。当前已完成 macOS / Windows 本地演示包。

## 从什么问题出发

歌单记录了不同歌曲的氛围，也可以成为个性化陪伴形象的起点。MeloPet 把歌单导入、氛围画像、音灵生成和桌面互动连接起来，让音乐偏好对应一个可选择、可互动的音灵。

## 用户怎样使用

1. 导入自己的歌单，等待歌曲处理与氛围分类。
2. 查看画像，对不合适的单曲分类进行纠正。
3. 生成音灵候选，选择喜欢的形象。
4. 点击“放到桌面”，启动透明置顶的动态桌宠。
5. 切换待机、聆听、跳舞或睡觉；浏览器最小化后，桌宠仍可驻留。

## 三个关键产品设计

### 从画像到形象形成完整路径

歌单氛围画像连接音灵候选和桌面呈现。用户可以查看分类并主动纠正，不必被动接受一次生成结果。

### 桌宠有独立的桌面交互

支持拖拽、点击切换动作、右键菜单、系统托盘或菜单栏、隐藏与退出，以及低动态模式。登录自启动需要用户主动开启。

### 降低本地演示的准备门槛

提供 macOS / Windows 一键启动器，首次运行检查并准备依赖。默认的本地规则与安全预览不要求配置外部模型密钥，也能完成核心演示。
